Grad Café Analytics
===================

A small data service that scrapes graduate-admission results from `Grad Café
<https://www.thegradcafe.com/survey>`_, stores them in PostgreSQL, and shows an analysis
page with **Pull Data** and **Update Analysis** buttons. Module 4 of *Modern Software
Concepts in Python* (Johns Hopkins University) adds a test suite with 100% coverage, a
GitHub Actions pipeline, and this documentation.
